# Chrome Web Store — Privacy tab, рабочий черновик

## Основное назначение
Расширение сохраняет выбранную пользователем переписку ChatGPT, хранит локальный архив, позволяет продолжить его и перенести результат в Google Docs или буфер обмена.

## Обрабатываемые пользовательские данные
Расширение получает доступ к содержимому открытой пользователем переписки ChatGPT только для выполнения функции сохранения/продолжения архива.

## Передача разработчику
Содержимое чатов не отправляется разработчику и не хранится на сервере разработчика.

## Локальное хранение
Архивы, настройки, состояние незавершённого прохода и технические данные лицензии хранятся в chrome.storage.local.

## Google Docs
Доступ к docs.google.com используется только когда пользователь сам запускает перенос/продолжение архива в Google Docs.

## Буфер обмена
Доступ к буферу обмена используется для копирования форматированного текста/изображений и для операций переноса в Google Docs.

## Вкладки и скрипты
tabs/activeTab/scripting нужны для открытия рабочей вкладки, проверки нужного чата и запуска content script в пользовательском сценарии сбора.

## debugger
debugger используется во время управляемого прохода длинного чата для взаимодействия с рабочей вкладкой и прокрутки/проверки состояния страницы. Перед отправкой в магазин ещё раз проверить, нельзя ли сузить реализацию и отказаться от этой permission без потери функции.

## offscreen
offscreen используется для операций с буфером обмена, которые нельзя надёжно выполнить из service worker.

## storage / unlimitedStorage
Нужны для локальной библиотеки длинных архивов и незавершённых проходов.

## Персональные идентификаторы
Расширение не требует собственного аккаунта и не собирает через интерфейс расширения ФИО, телефон или email.

## Платёжные данные
Банковские данные и данные карт не поступают в расширение; оплату обрабатывает внешний платёжный сервис.

## Важная проверка перед публикацией
Формулировки Privacy tab должны точно совпасть с фактическим кодом production-сборки и с privacy.html.
