Обычный экспорт быстро перестаёт быть удобным

В длинной переписке часть сообщений может находиться вне текущей страницы. Скриншоты не ищутся по тексту, PDF неудобно редактировать, а ручное копирование сотен сообщений отнимает время. Архиватор собирает именно структуру переписки, а не фотографию страницы.

Что умеет

Собрать, продолжить и не потерять уже сделанное

Собирает длинный чат

Физически прокручивает рабочую вкладку и заставляет браузер подгружать сообщения, которые не находятся на экране.

Фиксирует конец на момент запуска

Новые сообщения, появившиеся после старта, не должны случайно попасть в текущий снимок.

Продолжает сохранённый архив

Находит подтверждённый стык и добавляет только новые сообщения вместо полного повторного сбора.

Восстанавливает оборванный проход

Незавершённая часть сохраняется отдельно: её можно открыть, проверить, продолжить или удалить.

Не продолжает наугад

Если точку продолжения нельзя подтвердить, Архиватор останавливается вместо того, чтобы создать дубли.

Сохраняет редактируемый результат

Текст можно искать, копировать и менять. Сохраняются ссылки, списки, код, таблицы и изображения, когда их удаётся получить.

Как проходит сбор

Пять простых шагов

  1. 1
    Откройте нужный чат

    Архиватор работает с текущей перепиской ChatGPT.

  2. 2
    Выберите режим

    Основной — фоновая рабочая вкладка. Текущая вкладка остаётся резервным вариантом.

  3. 3
    Нажмите «Собрать чат»

    Архиватор зафиксирует нижнюю границу и начнёт проход.

  4. 4
    Дождитесь завершения

    Если проход оборвётся, уже собранная часть останется доступна для восстановления.

  5. 5
    Используйте результат

    Оставьте его локально, скопируйте целиком или перенесите в Google Docs.

Куда сохранять

Не привязывает архив к одному формату

Локальная библиотека

Готовые архивы остаются в Chrome и доступны для продолжения.

Буфер обмена

Скопируйте архив и вставьте его в Word, Notion, CMS, письмо или другой редактор.

Google Docs

Перенесите архив в новый документ или добавьте подтверждённое продолжение в уже связанный.

Для крупных архивов в продукте предусмотрено разбиение экспорта на части. Предельный объём для публичного обещания будет зафиксирован после отдельного live-теста.

Что происходит с перепиской

Архиватору не нужен собственный аккаунт пользователя

Содержимое чатов обрабатывается в браузере. Готовые архивы и незавершённые проходы хранятся в локальном хранилище расширения. При экспорте в Google Docs используется ваша открытая сессия Google.

Сервер разработчика для содержимого чатов не используется. Лицензионный ключ проверяется локально на устройстве и не содержит имя, email или телефон пользователя.

Для срочных тарифов срок лицензии начинается с момента выпуска ключа после подтверждения оплаты платёжной системой.
